# エピック_三期決算図 生成アプリ

このアプリケーションは、エピック株式会社の3つの決算書PDFファイルから財務データを抽出し、三期決算図を生成するためのツールです。

## 機能

- 3つの決算書PDFファイルから財務データを自動抽出
- 貸借対照表（バランスシート）の推移を可視化
- 損益計算書の推移を可視化
- 財務比率（売上高利益率、ROA、ROE）の推移を可視化
- 三期決算図の生成と保存

## 使用方法

### Windows版

1. `delivery/windows/エピック_三期決算図.exe` を実行します
2. 「PDFファイルを選択」ボタンをクリックし、3つの決算書PDFファイルを選択します
   - 例：エピック_6期決算書.pdf、エピック_7期決算書.pdf、エピック_8期決算書.pdf
3. 「出力先を選択」ボタンをクリックし、生成された図表を保存するフォルダを選択します
4. 「三期決算図を生成」ボタンをクリックして処理を開始します
5. 処理が完了すると、選択した出力先フォルダに以下のファイルが生成されます：
   - エピック_三期決算図.png（メインの三期決算図）
   - エピック_財務データ.csv（抽出された財務データ）
   - charts/フォルダ（個別のグラフ画像）

### macOS版

1. `delivery/macos/エピック_三期決算図` を実行します（ターミナルから実行する場合は実行権限を付与してください）
2. 以降の操作はWindows版と同様です

## 財務データの解釈

このアプリケーションは、PDFから以下の財務データを抽出します：

### 貸借対照表（バランスシート）項目
- 現金及び預金
- 売掛金等
- たな卸資産
- 資産合計
- 買掛金等
- 短期借入金
- 長期借入金
- 資本金
- 利益剰余金
- 純資産合計

### 損益計算書項目
- 売上高
- 売上原価
- 売上総利益
- 販売費及び一般管理費
- 営業利益
- 経常利益
- 税引前当期純利益
- 当期純利益

### 財務比率
- 売上高利益率（当期純利益÷売上高）
- ROA（当期純利益÷資産合計）
- ROE（当期純利益÷純資産合計）

## 注意事項

- PDFファイルの形式によっては、データ抽出の精度が変わる場合があります
- 抽出されたデータは必ず目視で確認してください
- 財務分析は参考情報であり、投資判断等には専門家の助言を求めてください
