# 三期決算図 生成アプリケーション (maru1)

このリポジトリには、三期決算図を生成するためのアプリケーションが含まれています。

## ダウンロード方法

### macOS版

1. `macos/maru1.app` フォルダをダウンロードします
2. ダウンロードしたフォルダを「アプリケーション」フォルダに移動します
3. 初回起動時は右クリックして「開く」を選択し、警告が表示されても「開く」をクリックしてください

### Windows版

1. `windows/maru1.exe` ファイルをダウンロードします
2. ダウンロードしたファイルをダブルクリックして実行します

## 使用方法

1. アプリケーションを起動します
2. 「PDFファイルを選択」ボタンをクリックし、3つの決算書PDFファイルを選択します
   - 例：エピック_6期決算書.pdf、エピック_7期決算書.pdf、エピック_8期決算書.pdf
3. 「出力先を選択」ボタンをクリックし、生成された図表を保存するフォルダを選択します
4. 「三期決算図を生成」ボタンをクリックして処理を開始します
5. 処理が完了すると、選択した出力先フォルダに以下のファイルが生成されます：
   - エピック_三期決算図.png（メインの三期決算図）
   - エピック_財務データ.csv（抽出された財務データ）

## 注意事項

- PDFファイルの形式によっては、データ抽出の精度が変わる場合があります
- 抽出されたデータは必ず目視で確認してください
- 財務分析は参考情報であり、投資判断等には専門家の助言を求めてください
